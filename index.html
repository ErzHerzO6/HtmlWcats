Module 0 • Welcome!

How Websites Actually Work 🐱✨

Secret confession from software engineers: websites aren't magic. Every website you've ever visited is just a plain text file that your browser dresses up!

🪵 HTML = The Cat Tree Frame

HyperText Markup Language puts the raw pieces onto the page: headings, paragraphs, images of cats, buttons, and links. Without CSS, it looks like a plain 1995 Word document.

🎨 CSS = Plush Cushions & Paint

Cascading Style Sheets makes everything pretty and organized: warm colors, fonts, rounded corners, side-by-side columns, and smooth hover animations.

🪄 2-Minute Icebreaker: Hack Any Website! Right-click anywhere on this page (or open Wikipedia), click Inspect, double-click any text inside an <h1> tag, and change it to "Breaking News: Cats Now Run the Government". Notice two things:
  1. Real websites use the exact same tags you are about to learn today!
  2. Refreshing the page resets it, because you only edited your browser's temporary copy.

Module 1 • HTML Basics

HTML Tags: Making Sandwiches with Text

In HTML, we wrap pieces of content inside tags using angle brackets < > so the browser knows what each piece is.

Interactive Explorer

Click Each Piece of This HTML Link:

<a href="https://cats.com" > Pet Mochi! </a>
1. Opening Tag <a ...>: Tells the browser "Start a clickable link right here!" Think of it as the top slice of bread in a sandwich.

📋 Your Starter Pack of HTML Tags

Tag What It Creates Example
<h1> to <h6> Headings (h1 is biggest, h6 is smallest) <h1>Meet Mochi</h1>
<p> A normal paragraph of text <p>She loves naps.</p>
<strong> / <em> Bold importance / Italic emphasis <strong>Very</strong> fluffy
<ul> & <li> Unordered bullet list + list items inside it <ul><li>Tuna</li></ul>
<a href="..."> Clickable link (target="_blank" = new tab) <a href="#menu">Menu</a>
<img src="..." alt="..."> Image! Special rule: No closing tag needed! <img src="mochi.svg" alt="Cat">

🏠 Every HTML File Has Two Rooms: <head> & <body>

index.html 
<!DOCTYPE html>
<html lang="en">
<head>
  <!-- 🧠 BRAIN (Invisible settings, tab title & CSS link) -->
  <meta charset="UTF-8">
  <title>Browser Tab Title</title>
</head>
<body>
  <!-- 👀 VISIBLE PAGE (Everything your visitor actually sees!) -->
  <h1>Hello from Mochi!</h1>
</body>
</html>

Module 2 • Clean Structure

Semantic HTML5: Labeling Your Moving Boxes 📦

Imagine moving into a new apartment where all 40 cardboard boxes just say "BOX" (<div>). You'd go crazy! Semantic HTML gives your page sections meaningful labels.

❌ "Div Soup" (Hard to read)

<div> Top Bar & Links </div>
<div>
  <div> About Shelter </div>
  <div> Cat Card </div>
</div>
<div> Copyright & Address </div>

✅ Semantic HTML5 (Crystal clear!)

<header> + <nav> Links </header>
<main>
  <section> About Shelter </section>
  <article> Cat Card </article>
</main>
<footer> Copyright & Address </footer>
🔗 Bonus Superpower: Page Jump Links! If you give any section an ID like <section id="residents">, you can make a link jump straight to it on click using <a href="#residents">Our Cats</a>!

Module 3 • Styling Begins

Hello CSS! Colors, Fonts & Selectors 🎨

Now let's make things look good! We write CSS in a separate file (style.css) and connect it inside our HTML <head> with one magic line:

Inside <head> in index.html
<link rel="stylesheet" href="style.css">

🎯 How CSS Picks Which Elements to Paint

Every CSS rule has a Selector (who to style) followed by curly braces { } containing property: value; pairs:

Interactive Selector Tester

Click a CSS Selector to See Which Cats Get Styled:

Mochi <article class="sleepy">
Sir Whiskers <article class="dapper">
Luna <article class="sleepy" id="luna-vip">
💡 Rule of Thumb: Use .classes 90% of the Time!
  • No symbol (p, h1, body) = styles every tag of that type.
  • Dot . (.card, .highlight) = styles any element with class="card". Reusable and flexible!
  • Hashtag # (#banner) = styles one single unique id="banner".

          Module 5 • Modern Page Layouts
          
Flexbox: Cats on a Sunny Windowsill ☀️🐾

          

            By default, HTML stacks block elements vertically from top to bottom. How do modern websites put a logo on the left, links on the right, and 3 cards side-by-side? Meet Flexbox!
          


          

            👑 The Golden Rule of Flexbox:
            You always put display: flex; on the PARENT container (the windowsill), and all of its direct children (the cats!) immediately line up side-by-side!

          Module 6 • Polish & Delight
          
Hover Magic & Smooth Transitions ✨

          

            What separates a beginner page from a polished, tactile frontend? Subtle feedback when you move your mouse (:hover) or click (:active)!
          


          
          

            Feel the Difference
            
Hover Your Mouse Over Both Cards Below:


            

              

                
                
❌ Without transition

                

                  Teleports abruptly! Feels jumpy and robotic.
                

              


              

                
                
✅ With transition: 0.28s ease

                

                  Glides smoothly up and floats gently back down!
                

              

            

          


          

            
The Hover Lift Recipe

            
.cat-card {
  /* Put transition on the BASE class (not :hover) so mouse-out is smooth too! */
  transition: transform 0.25s ease, box-shadow 0.25s ease;
}

.cat-card:hover {
  transform: translateY(-8px); /* Negative Y moves UPWARD by 8 pixels! */
  box-shadow: 0 18px 36px rgba(0, 0, 0, 0.14);
}

          Module 8 • Reference
          
5-Second Bug Fixer & Cheat Sheet 🩺

          

            Even 10-year senior developers hit CSS bugs every single day. Whenever something doesn't change on screen, run down this 5-step checklist!
          


          

            🚨 "Why Isn't My CSS Working?!" Checklist
            
    
              
  1. Did you save BOTH files? Check for a little dot next to index.html and style.css and press Ctrl + S!
    2. 
              
  2. Did you refresh the browser? Press F5 or Ctrl + R.
    3. 
              
  3. Is <link rel="stylesheet" href="style.css"> inside <head>? Double-check the filename spelling!
    4. 
              
  4. Did you forget the dot . on a class? class="cat-card" needs .cat-card { ... }, NOT cat-card { ... }!
    5. 
              
  5. Check the line ABOVE for a missing semicolon ; or }! One missing semicolon disables the property right below it.
    6. 
            

          


          
⚡ Essential Properties at a Glance

          

            
              

                What You Want to Do
                Exact CSS to Write
              

            
            
              

                Center text inside an element
                text-align: center;
              

              

                Center a box with a width on the page
                width: 350px; margin: 0 auto;
              

              

                Put items side-by-side in a row
                display: flex; gap: 24px; (on parent!)
              

              

                Push logo left & nav links right
                display: flex; justify-content: space-between; align-items: center;
              

              

                Add breathing room inside a card
                padding: 24px;
              

              

                Make smooth rounded corners (or pill shape)
                border-radius: 20px; (or 999px for pills!)
              

              

                Remove underline from links
                text-decoration: none;
              

              

                Remove bullet points from a <ul>
                list-style: none; padding: 0;
